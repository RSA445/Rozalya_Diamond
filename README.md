# Rozalya Diamond 💎

A website for a gold and diamond jewelry store, built with HTML and CSS. It showcases earrings, necklaces, bracelets and rings with a welcoming home page and a shop page.

> **Status:** in progress. The home and shop pages are built; the About, Enhancements and Enquire pages and the stylesheet are still empty.
